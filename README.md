# 爱弥斯 · 像素飞行

粉色头发、机械翅膀，始终面朝正面的像素桌宠。平时轻轻扇翅膀悬停，偶尔飞一飞；被摸头时会冒出爱心，收到点歌请求时会播放包内收录的歌曲。

这是用于 **Coopanion** 的形象包，当前发布版为 **1.0.0**。聊天、模型接入和语音输入由 Coopanion 与你启用的模型提供；本项目负责像素形象、互动动作和随包录音播放。

## 安装与更新

1. 先安装 Coopanion，再打开「装扮」→「形象」→「导入」。
2. 选择 `aemeath-pixel-flight-1.0.0.zip`，导入后选中「爱弥斯·像素飞行」。
3. 更新同名形象时，按界面提示选择重装或更新。同为 1.0.0 的旧文件不一定有相同内容，以本次提供的包为准。
4. 想听声音，开启音效总开关及动作、表情、触摸等相应类别。首次使用时，请等待音频加载完成。
5. 想让她自己活动，在软件里开启自动活动；关闭时仍可点击、抚摸或发送动作指令。

形象包 ID 为 `aemeath-pixel-flight`，与正常版不同，可以同时保留。

## 她会做什么

| 功能 | 使用方式与表现 |
|---|---|
| 点击表情轮换 | 开心 → 期待 → 慌张 → 喜欢 → 装晕，再回到开心。每次点击切换到下一项，动作持续约 3 秒后回到悬停。 |
| 摸头与抚摸 | 不按鼠标键，在头部或身体上来回移动，会冒爱心。持续抚摸会续播当前反应，不反复重置动画。 |
| 悬停、飞行和拖动 | 悬停持续扇翅，移动保持正面朝向；可以上下、左右飞行，拖动松手后原地悬浮。 |
| 自主小动作 | 开启自动活动后，会随机张望、开心扑翼或闭眼休息；动作之间留出悬停间隙。 |
| 随机跳舞与短哼唱 | 自动活动开启时，约每两分钟跳舞并播放短啦啦啦；忙碌时顺延，不积累补播。 |
| 内置 8 首点歌 | 直接说歌名或用日常说法点歌，由 AI 调用对应动作播放包内录音；播放期间持续跳舞，结束后回到悬停。 |
| 窗口顶边停靠 | 在能取得窗口顶边信息的环境中，可通过移动目标「窗口顶边」停到能容纳角色的可见顶边；拖动解除停靠，顶边消失后恢复悬浮。 |
| 状态反馈与音效 | 聆听、思考和说话时都有相应提示；点击使用抓起音效，表情及抚摸保留团子录音反馈；抚摸不再播放 purr 音效。 |

开心和说话使用微笑扑翼素材，张望是整个人物轻晃。当前没有独立口型、独立视线或挥手动画；装晕通过闭眼、淡化和星点表现。

## 内置 8 首点歌

直接按平时说话的方式点歌，**不需要书名号**：

```text
唱个星炬不熄
来个纸飞机
放一下小小奇迹
给我唱个碎花
唱一首歌
```

| 收录歌曲 | 英文名 | 可以这样说 |
|---|---|---|
| 纸飞机 | Paper Plane | 来个纸飞机 |
| 靛青宇宙 | Indigo Universe | 唱个靛青宇宙 |
| 碎花 | Fallen Petals | 给我唱个碎花 |
| 星炬不熄 | Unwavering Startorch | 唱个星炬不熄 |
| 小小奇迹 | A Small Miracle | 放一下小小奇迹 |
| 极限迪斯科 | Deadline Disco | 来个极限disco |
| 远航星的告别 | Voyaging Star's Farewell | 唱个远航星的告别 |
| 那颗星梦见的春日 | Vernal Days Dreamed by the Star | 来个春日 |

- 唱歌、唱一首歌、听歌：随机选一首完整歌曲。
- 指定歌名：播放对应完整录音，兼容中英文名、常见简称和部分同音写法。
- 哼歌、啦啦啦、跳舞：仍使用原来的短啦啦啦。
- 随机活动只播放短哼唱，不会突然自行播放整首歌。

这是**播放已有录音**。AI 需要实际调用形象包的歌曲动作，仅在文字里答应唱歌不会出声；未收录的歌曲无法点播；语音识别出错时，也可能无法匹配歌名。

### 如果她还说只能哼歌

先确认导入的是包含八首 MP3 的点歌版，并启用了音效。随后使用软件的 **重载系统前缀** 功能，更新实际会话里的动作词表。

提示词预览出现新动作，不代表已经保存的会话也更新了；只切换形象或重启软件，也可能继续沿用旧前缀。正常重载无需清空聊天记录。

## 已知问题与能力边界

以下播放控制限制按**原版 Coopanion** 说明；没有把开发预览中的扩展能力写成原版已经支持。

| 情况 | 当前说明 |
|---|---|
| 双击停歌、停止歌曲指令 | 原版暂不支持，作为已知问题保留。 |
| 歌曲未结束时再点另一首 | 不会立即切歌，播放期间收到的新请求会被忽略，不会自动排队。 |
| 临时需要中途停歌 | 真正退出 Coopanion 可以停止，桌宠也会一起退出；仅关闭设置窗口不等于退出。不保留歌曲进度。 |
| 开发预览可以停止或切歌 | 预览接入了扩展宿主接口；单独重新导入 ZIP 不会给原版软件增加该接口。 |
| 播放缓存 | 八首 MP3 约 52.2 MiB。按 48 kHz 双声道浮点估算，解码缓存约 606 MiB，另有其他开销；这是根据音频参数估算的缓存大小，尚未实测进程内存占用。 |
| 平台与模型差异 | 窗口顶边读取、Windows 安装版和各模型的点歌稳定性尚未全部实测。 |
