# 爱弥斯·像素飞行 1.0.0

基于现有角色素材制作的 Coopanion 形象包，实现点击表情轮换、抚摸反馈、随机唱歌、自动飞行及窗口停靠。

日常点歌直接说：唱个星炬不熄、来个纸飞机、放一下小小奇迹、唱一首歌。歌名不需要书名号；也兼容中英文名、常见简称和唱/放/听等说法。

通过 Coopanion 的形象包导入入口选择 `aemeath-pixel-flight-1.0.0.zip`，更新同名飞行形象。包 ID 与正常版不同，两者可以同时保留。

角色始终正面朝向。移动指令在当前高度左右飞行；上升、下降动作改变高度。拖拽松手后原地悬浮，不受重力影响。自动活动遵循应用传入的关闭、安静或自由设置；自主飞行目标有 80% 落在可活动高度的上部 45% 区域，其余在下部，安静模式逐段靠近目标。该比例是目标抽样概率，不是停留时间保证。松手后等待 8～15 秒再自行飞行。休息时保持悬浮闭眼。

未播放完整歌曲时，每次短点击人物任意部位，立即切换到下一项：“开心 → 期待 → 慌张 → 喜欢 → 装晕”，然后回到开心。连续点击不受时间冷却限制。点击动作持续 3 秒，期间循环播放对应动画，结束后回到悬停，不永久保持选中的表情；后续点击仍继续轮换。“悬停”动作立即恢复待机。重新加载形象后，从开心开始。

拖拽、抚摸和取消操作不推进轮换。移动鼠标超过 4 像素后进入拖拽，松手不再触发点击。短点击不取消模型移动指令，拖拽会中断并回执。表情切换不受音效冷却限制；连续点击时，团子语音仍遵循 3.15 秒防重叠间隔，点击使用的抓起短音效不受此限制。

不按鼠标键，在人物身上来回移动，会触发抚摸爱心；新的抚摸触发至少间隔 2.5 秒；持续抚摸只延长当前动画，不反复重置、叠加语音或推进点击轮换。开启自动活动时，飞行间隙会随机轻晃、开心扑翼或短暂闭眼。跳舞唱歌使用独立计时，每次间隔 105～135 秒，平均约两分钟；开启自动活动时开始计时。到期时若仍在飞行、监听、思考、对话或交互，等待空闲再跳；不补播积压次数。计时使用单调实际时间，不依赖帧率；后台页面暂停时无法执行动作，恢复后再检查到期。关闭自动活动会清除跳舞计时，重新开启从头计时；显式跳舞也会重设下次时间。跳舞不占点击轮换项，仍可从预览按钮或模型动作手动触发。

监听时两侧显示脉冲标记；思考时显示点状标记，遵循应用的思考提示开关。说话时微笑并轻微律动，停止后恢复监听、思考或待机。反馈优先级为拖拽、点击／抚摸、显式动作、说话、监听、思考、飞行或待机。监听和说话会唤醒休息中的角色。

形象词汇：悬停、上升、下降、飞行、疾飞、开心、期待、跳舞、休息、慌张、喜欢、张望、装晕。开心和说话使用微笑扑动动画，没有独立口型；张望使用整个人物轻晃，没有独立视线。

原始六段 MP3 保留在 assets/audio/。播放改用增强后的 PCM WAV：语音波形幅度乘 2，清单音量从 0.65 提到 1，混音前幅度约为旧版的 3.08 倍。原版点击、抓起、释放、抚摸音色用官方 sound.js 离线渲染后乘 3，以同名音效覆盖，仅影响本形象包。增强文件峰值最高约 0.779，低于数字满刻度，没有削波。宿主压缩器与系统音量会影响实际听感。映射如下：

| 文件 | 用途 | 触发 |
|---|---|---|
| voice_001.mp3 | 啦啦啦唱歌 | 喜欢、自主或显式跳舞，播放一次 |
| voice_003.mp3、voice_007.mp3 | 开心蹦跶两种 | 点击切换到开心／期待、抚摸、显式开心／期待动作，交替播放 |
| voice_002.mp3、voice_004.mp3、voice_006.mp3 | 死亡音效三种 | 慌张或装晕，依次轮换 |

装晕用闭眼、淡化和星点表现，没有专门的死亡动画素材。点击装晕持续 3 秒后恢复；显式装晕播放一个闭眼周期（2.75 秒）后恢复。声音只在触发时播放，不随保持状态重复播放。拖拽、飞行和自主活动不会播放死亡音效。自主开心动作保持无声，自主跳舞可以唱歌。

即时反馈音效：点击与抓起统一使用 grab、释放 pop、抚摸 purr。通过清单中的同名增强 WAV 覆盖，归入 touch 分类，遵循触摸音效开关与总静音。每次有效点击都会请求一次 grab，不受团子语音冷却影响；表情轮换和对应语音保持。

两次团子语音至少间隔 3.15 秒。当前语音播放时只保留最新一条待播语音，前一段结束后播放，不积累多条。切换到无语音动作、开始拖拽、监听、思考或对话时清除过时待播项。当前语音仍播放到结束；宿主 API 2 没有停止已播放声音的方法。应用的音量、静音、动作与表情分类开关继续生效。应用自身的对话提示音仍由应用设置控制，没有增加整段回复朗读。

`figure.json` 的 `sounds` 登记音频路径、分类与音量；`animations.json` 的 `soundCues` 将事件映射到声音名，数组按顺序轮换。所有播放经过 `host.sound()`。没有映射的事件保持无声。

待补素材：疑惑、难过、生气、害羞的专门表情，以及独立口型、视线和招手等动作。当前未用笑脸代替这些表情，也未将它们登记为已支持词汇。

- `figure.js`：形象 API 2 的入口、图集加载与渲染。
- `flight.js`：二维位置、飞行、拖拽、屏幕边界和动作回执。
- `animations.json`：动画帧坐标、原始帧时长与素材来源文件名。
- `assets/`：透明 PNG 图集和缩略图。

软件更新后，先检查能否加载、移动回执、拖拽悬停和屏幕边界。接口变动集中检查 `figure.js`；当前包不依赖应用内部模块。

预览：在工作目录运行 `node scratch/pixel-flight/server.mjs`，打开 http://127.0.0.1:4322/ 。预览使用当前源码的真实形象沙箱，不访问已安装应用的数据。

1.0.0 已通过 41 项行为测试和 0.2.5 源码形象清单、资源及布局检查；已在隔离的 Edge 中验证官方沙箱加载、八首 MP3 解码、实际点播与防叠音。尚未在已安装的 Coopanion 中实际导入；未验证不同版本软件的兼容性。重启应用会重新选择初始高度，API 2 没有向形象包传入历史纵坐标。

## 0.2.5 移动接口与自动活动

`pet_move_to` 的默认目标保留当前高度水平飞行。自定义目标 `point` 接受 x、y 两个 0～1 参数（可省，默认各 0.5），对应可活动区域从左到右、从上到下；`window-top` 飞到最近且能容纳角色的可见窗口顶边。

包声明 `needs: ["windows"]`。没有可用顶边时返回 `interrupted / no-window`；飞行中目标顶边消失时返回 `window-gone`。拖动解除停靠；顶边消失后在当前位置悬浮，不持续跟随窗口。浏览器没有真实窗口数据时自由飞行照常可用。macOS 的真实窗口读取尚未实测。

无人操作时，小动作完成后等待 6～9 秒再选择下一个小动作（飞行忙碌时顺延）；选择权重为张望 55%、开心扑翼 10%、闭眼休息 35%。休息持续 10～15 秒，结束后再等待。自动飞行结束后的起飞等待随机取 8～15 秒，休息可延后起飞。随机唱歌跳舞仍按独立 105～135 秒时钟触发，忙碌时顺延。点击继续即时轮换表情。

## 动作结束与悬停

点击开心、期待、慌张、喜欢、装晕统一持续 3 秒，期间循环播放图集，结束后回到悬停。显式开心、期待、慌张、喜欢、装晕、跳舞、休息动作仍播放一个图集周期，随后回到悬停；悬停持续循环原有的轻扇翅膀待机动画，并保留轻微位置浮动。飞行和拖动等持续状态在状态结束前循环播放。动作从匹配的衔接姿势开始，点击仍立即切换；在三秒内按完整周期播放后回到对应悬停帧。自动休息仍保留 10～15 秒，闭眼动画播完后停在末帧，等待休息结束。自动跳舞约两分钟一次的触发时钟保留，单次动画为 1.48 秒。动作结束后由原有活动计时决定何时飞行或执行下一项，不立即连播。语音播放与动画周期独立，已播放的语音仍自然结束。

## 窗口停靠边界

顶边必须容纳整个绘制框的宽度；已经停靠或飞往顶边时，也持续核对这段完整宽度，顶边缩窄或移走则解除停靠/中断飞行。脚部锚点使用当前实际播放帧身体中央的脚部像素位置，和渲染器共用选帧函数，避免把翼尖最低点当成脚底。

停靠通过模型调用 window-top 或预览按钮触发，自主飞行不会自动挑选窗口。开启自动活动后，人物仍会按飞行计时自行离开。接口没有窗口标识，因此只核对可见顶边的几何，不跟随特定窗口，也无法区分几何完全相同的两个窗口。宿主约每 0.7 秒刷新窗口数据，解除停靠受刷新延迟影响。

## 悬停翅膀增幅

以 0.3.11 的原悬停 idle 图集为基础，按各侧翅膀绕翼根的角度偏差增加约 50%，生成 hover-wide 图集。身体和手臂区域逐帧保留原像素，在 0.3.16 上再提速 50%，按原速度 1.875 倍播放，周期约 0.94 秒；移动使用原 fly 图集，悬停使用 hover-wide 图集，点击三秒后悬停等行为保持。

自动小动作间隔为 6～9 秒、飞行等待 8～15 秒。小动作不重新推迟已经排定的飞行，到期遇到动作播放、休息或交互则等待空闲。当前悬停扇翅周期约 0.94 秒、点击三秒反馈、休息持续时间及随机权重保持。

## 移动时长与衔接

普通非零距离飞行至少 3 秒，按距离 / 100 计算时长；加速飞行至少 1.5 秒，按距离 / 180 计算时长，移动时长按完整飞行周期向上对齐，并留出工具超时余量。位移采用五次平滑曲线，起点、终点速度和加速度为零。飞行保留原 fly 图集及其 0.88 秒周期；悬停保留 hover-wide 和约 0.94 秒周期。零距离立即完成。自动动作间隔与三秒点击反馈保持。

起飞前等待当前悬停到达匹配姿势（最多约 0.94 秒）；飞行从原第 7 帧的中间开始，完整周期后回到该姿势，再切到悬停第 9 帧。两帧头顶与脚底高度相同，窗口停靠也按此落地姿势定位。原图像和帧时长保持。普通飞行实际常见最短为 3.52 秒，另有起飞等帧时间。

## 动画状态集中修正

持续抚摸播放完整开心周期，鼠标仍移动时续播，不再在 0.88 秒后停帧；停手后完成当前周期并接回匹配悬停姿势。起始先等到悬停衔接姿势，爱心即时显示。整次抚摸只触发一次抚摸音和语音，点击或拖动可中断。

点击各动作仍为三秒，通过轻微调整各自播放速度，使完整周期在三秒时恰好到达收尾姿势。显式动作和自动开心也正确按完整周期运行。张望、监听、思考共用当前悬停图集与扇翅时钟；张望倾斜起止回零。闭眼休息/装晕绘制基准上移 10 个素材像素，减少原图基准差造成的下沉。飞行缩放后的剩余时长重新对齐收尾周期。原飞行图集、各原始 PNG、音频均未改变。

素材限制：舞蹈（墨镜、颜色和身体比例）、拖动（挣扎姿势）、闭眼等状态本来就有造型变化，本次没有重画或补造过渡帧。已校准的身体基准与状态时钟不等于所有素材像素完全相同；不同造型仍可看出切换。语音时长独立于动画，宿主不支持停止已经播放的语音。

## 唱歌与点歌彩蛋

“唱歌”“唱首歌”“听歌”随机播放一首完整歌曲；指定歌名时播放对应曲目。“哼歌”“啦啦啦”“跳舞”仍使用现有短音频。模型通过 pet_act 或 pet_say 动作标记调用，单纯回复文字不会播放声音。须启用音效及动作类别音效。

| 曲目 | 英文名 | 点歌示例 |
|---|---|---|
| 纸飞机 | Paper Plane | 唱纸飞机、播放纸飞、PaperPlane |
| 靛青宇宙 | Indigo Universe | 唱靛青宇宙、播放靛蓝宇宙、IndigoUniverse |
| 碎花 | Fallen Petals | 唱碎花、播放碎花歌、FallenPetals |
| 星炬不熄 | Unwavering Startorch | 唱星炬不熄、播放星炬不灭、UnwaveringStartorch |
| 小小奇迹 | A Small Miracle | 唱小小奇迹、播放小小奇跡、ASmallMiracle |
| 极限迪斯科 | Deadline Disco | 唱极限迪斯科、播放极限、DeadlineDisco |
| 远航星的告别 | Voyaging Star's Farewell | 唱远航星的告别、播放远航告别、VoyagingStar'sFarewell |
| 那颗星梦见的春日 | Vernal Days Dreamed by the Star | 唱那颗星梦见的春日、播放春日、VernalDaysDreamedByTheStar |

点歌语句由模型理解，再调用登记的动作 ID。词表兼容中英文名称、简称、常见写法及唱/放/听等前缀，不保证任意语音识别错误都能匹配。比如“极限disco”“极限迪斯科”是同一首；“星炬不息”兼容“星炬不熄”。

完整歌曲只由点歌动作触发；随机活动继续播放短啦啦啦。每次播放整首一次，整首期间按原速循环舞蹈，结束后回到悬停。支持音乐控制的宿主上，新点歌立即停止旧歌并切换；唱歌时双击人物立即停止，单击不停止且不推进表情轮换；拖动不会误触停止，松手后继续跳舞。也可用“停止唱歌”“停歌”“别唱了”等指令停止。停止或自然结束后重新安排自动唱歌计时，不补播积压动作。表情短语音在完整歌曲期间暂不播放，点击、抓起等短反馈音继续生效。正在播放的短语音先预留原有冷却时间，再开始歌曲。

官方原版 0.2.5 的 API 2 只有播放。当前本地源码已新增可协商的音乐控制：宿主通过 musicControl 标记能力，独占音乐通道支持立即换歌和停止，静音会降低已启动音源的增益，换形象会清理该通道。旧宿主不提供停止词，保留自然播放；单独重导形象包不能升级旧宿主。当前预览已使用更新的源码，已安装应用尚未重新构建或替换。计时按单调实际时间运行，后台恢复不补播。宿主未解码完成、静音或隐藏时可能没有实际声音，包接收不到播放完成回执。

八首歌曲直接使用用户提供的 MP3，没有转码或倍增音量。歌曲 MP3 合计约 52.2 MiB；原始 MP3 与 FLAC 只按中文曲名重命名，音频内容未修改。宿主会预加载并解码全部音频：按 48 kHz 双声道浮点缓冲估算，八首歌约占 606 MiB，另有压缩文件及其他开销；压缩包大小不代表播放缓存大小。

宿主源码补丁为同级 `Coopanion-0.2.5-音乐控制.patch`，不包含歌曲素材。预览首次点歌会自动启用音效并等待准备完成；双击人物可取消尚在准备的点歌。

## 模型点歌能力说明

完整歌曲通过现有 pet_act 动作执行，不需要新增音乐工具。原版 0.2.5 可以播放指定歌曲；musicControl 是停止/切歌能力标记，不是点歌播放的前提。例如“唱纸飞机”对应 `pet_act({"actions":["song-paper-plane"]})`，“唱一首歌”对应 `pet_act({"actions":["sing"]})`。`dance` 只代表短啦啦啦，不应替代已经收录的指定歌曲。

清单的身体说明及每个歌曲动作都给出准确调用和支持边界，供模型环境词表读取。导入后切换形象可重新加载身体。若模型仍说不能点歌，应使用软件的“重载系统前缀”功能更新实际会话；提示词预览有新动作不代表已持久化的 system 消息已更新，重启也可能继续沿用旧前缀。不要仅凭显示的同一个 1.0.0 版本号判断是否导入最新内容。

口语点歌补充：唱个星炬不熄、唱个星炬不息、来个纸飞机、放一下小小奇迹、给我唱个碎花，均按普通文本识别，不要求书名号。

已确认的同步问题：当前会话会持久化系统前缀，安装新版形象包后可能仍沿用旧动作说明。排查时应区分提示词预览与实际 session 的 system 消息；优先用官方“重载系统前缀”，无需清空聊天。

双击归属：支持音乐控制的宿主中，完整歌曲播放期间由形象接管双击以停止歌曲；没有播放完整歌曲时仍保留应用原来的双击聊天设置。双击停止不保留歌曲进度。
